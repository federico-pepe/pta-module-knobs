## Project

`pta-module-knobs` — Node.js process module for
[push-tethered-app](https://github.com/federico-pepe/push-tethered-app): a
test bench for the three knob compositions (`knob`, `knobfull`, `knobarc`).
It talks to the host only through the JSON-over-stdio process-module
protocol. Full description: [README.md](README.md).

## Rules

- Protocol reference: push-tethered-app's
  `docs/guides/writing-a-process-module.md` and
  `docs/guides/writing-a-javascript-module.md`.
- `palette.json` is generated by push-tethered-app's `cmd/genpalette`. Do not
  hand-edit it.
- Module version lives in `manifest.json` `version`. Bump it on a meaningful
  change. Release: push a matching `vX.Y.Z` tag;
  `.github/workflows/release.yml` packages it.
